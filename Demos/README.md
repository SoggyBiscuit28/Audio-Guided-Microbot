# Demo Videos

This folder contains demonstration videos of the Audio-Guided Microbot project.

## Project Demo

📹 **[Watch the Demo Video](https://drive.google.com/file/d/1aCh8zQsNOZ-Cvipodxt4e_dWg6QOUhP8/view?usp=drivesdk)**

The demo showcases:
- Voice command recognition (Forward, Backward, Left, Right)
- Real-time motor control based on audio classification
- BLE communication with the companion GUI
- Obstacle detection and avoidance
- Manual override using the Python GUI

---

## Features Demonstrated

| Feature | Description |
|---------|-------------|
| Voice Commands | ESP32-S3 recognizes spoken commands using on-device ML |
| Motor Control | Differential drive responds to classified commands |
| BLE Communication | Real-time status updates and manual control |
| Obstacle Detection | Ultrasonic sensor prevents collisions |
| GUI Control | Python application for monitoring and override |
